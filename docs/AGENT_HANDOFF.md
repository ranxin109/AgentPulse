# Agent 开发交接

接手后先读本文件，再根据任务读取维护文档；接入上报不需要读全部 C# 源码。

## 现有结构

|文件|责任|
|---|---|
|`src/Program.cs`|入口、单实例、数据目录与已有窗口恢复|
|`src/TaskStore.cs`|任务解析、权重进度、排序、历史、原子保存、自检|
|`src/BulkOperations.cs`|批量确认、故障清理和菜单启用条件|
|`src/ProgressWindow.cs`|列表/详情、计时、数据轮询、拖拽排序、入场/已阅退场、窗口区域|
|`src/Controls.cs`|绘制控件、图标、滚动与进度扫光|
|`src/WindowSizing.cs`|列表编辑模式、保存取消、详情标题与工作区适配|
|`src/WindowPreferences.cs`|固定开关及持久保存|
|`src/CompactView.cs`|圆环与列表切换、圆环任务选择、两种布局同步保存|
|`src/CompactRingWindow.cs`|独立逐像素透明窗口、渐变抗锯齿、直接拖动、滚轮和边缘缩放|
|`src/CompactGeometry.cs`|圆环保存读取与恢复列表的锚点计算|
|`src/AdaptiveListSizing.cs`|按内容收紧列表、高度上限、详情独立阅读高度|
|`src/ScreenBounds.cs`|移动/缩放消息中的实时工作区限制|
|`assets/app-icon.png`、`assets/app-icon.ico`|用户已确认的圆环＋光点图标，PNG 原稿与多尺寸 Windows 图标|

构建仅编译 `src/*.cs`。旧备份、老单文件脚本和运行数据不属于仓库源码。本仓库的三个发布/启动/新建脚本基于实际安装版；上传版启动助手额外接受 `WidgetPath`，方便自定义安装。不含旧 `progress_widget.ps1` 实现。

build.ps1 在 assets/app-icon.ico 存在时将图标嵌入 EXE；列表和圆环使用可执行文件关联图标，桌面快捷方式优先引用安装目录 assets 下的 ICO。安装时复制 assets。项目图标是用户批准的发布素材，不是任务历史或桌面截图。

## 必须保留的行为

1. 短任务不创建追踪；有用事件驱动上报，没有额外模型定时心跳。
2. 多 Agent 独立任务文件与稳定阶段 ID。主任务只按已经收到的证据汇总。
3. 完成时真实完成报告与时间，保留开始/已阅状态；不把其他任务的陈旧数据自动改成完成。
4. 每段进度有实际依据，预估可选，使用真实暴露的模型信息。
5. 列表简约且隐藏滚动条，历史/关闭等在右键菜单；已阅先置灰禁点、约 3 秒后退场。
6. 主列表所有未阅任务按创建时间倒序（created_at 优先，旧数据 started_at 回退），完成/更新不改变位置。旧手动队列被忽略，拖动排序入口已关闭。历史仍按已阅时间排序。
7. 最小化只选队列中首个未完成任务，直接移动；调整后自动保存。恢复列表先按当前内容计算高度，再靠近圆环展开，空间不足时改变增长方向；不要沿用旧大窗口高度造成远距离偏移。
8. 列表编辑仍要求显式进入模式并保存/取消。圆环菜单调整不应强制恢复列表。
9. 移动/缩放在当前操作开始时所在的屏幕工作区内实时限制，不是只在松手后纠正。
10. 超时红色是报告过期提示，不能冒充已验证的任务失败；completed 永不按过期变红。awaiting_confirmation 表示等待用户决定，始终橙黄、排除超时清理；failed 只用于明确失败。
11. 批量已阅只能处理已完成任务，复用置灰禁点和延迟退场；故障清理先确认再进回收站，在锁内重新判定，保护刚恢复的任务。
12. 组件启动后保持运行，任务完成、清空、聊天结束均不自动关闭。Agent 不得自动关闭、终止或重启组件，测试和更新也不例外。需退出时由用户自行关闭，先准备可更新的版本。
13. 用户可双击桌面“一键启动任务组件”，直接启动原生程序；已有实例走原生单实例激活逻辑。create-shortcut.ps1 和 launch.cmd 不终止任何进程，快捷方式默认由安装脚本创建。
14. 单实例锁按窗口站和桌面区分，避免 Codex 隔离桌面实例阻止用户普通桌面启动。激活优先选择可见列表/圆环；无法找到窗口时明确提示，不静默退出。launch-diagnostics.log 属于本机私有运行日志，不提交。
15. 主列表按实际内容自适应高度，任务少时收紧，达到用户高度上限后滚动；宽度仍由用户设置。编辑时不自动收缩。list-height-limit.txt 只在用户保存尺寸时修改，详情高度不能覆盖列表上限。

## 已实现与验证边界

按需追踪、增量 patch、新建助手、可配置数据目录、可选预估与阶段权重均已实现。原生编译、数据自检和 PowerShell 5.1/7 发布检查通过。

列表采用隐藏滚动条与自适应高度；圆环使用逐像素透明窗口，支持直接拖动、缩放和保存位置。列表与圆环分别保存布局，恢复列表时重新计算当前内容高度。当前列表排序以创建时间为准，拖动排序入口已关闭。

最终圆环重启位置、长详情连续滚动、部分菜单动画、多屏 DPI 与性能仍需要桌面验收；不要用数据自检替代交互验收。详见 [VERIFICATION.md](VERIFICATION.md)。

## 桌面操作约束

仅定位和操作已经确认的 ProgressWidget 窗口，不关闭或终止无关应用。桌面工具错误应按实际结果记录，不猜测原因或将关闭其他软件当作修复方法。

使用 Computer Use 的官方接口，先观察再执行一个操作并刷新；菜单截图可能与主窗口截图顺序不同，按实际尺寸/截图 ID 选坐标。输入坐标必须在截图边界内。用户 Esc 停止时立刻停用该轮电脑操作。没有工具时继续可做的代码工作，但明确桌面验收未完成。

不得通过通用 Alt+F4 或按进程名称批量终止程序来清理桌面。组件关闭也由用户操作，Agent 不得为部署或检查自动结束组件；更改部署前保留备份。用户真实任务与窗口设置不用于公共演示，也不提交 GitHub。

## 建议的交接记录格式

记录具体修改、构建结果、实际检查动作、观察到的结果、剩余待办；附文件和命令的可复现入口。失败时写事实和下一步，不猜根因。模型仅记录当前运行环境暴露的信息。

不会或不知道或无法解决的就直接告诉我，不要提供虚假方案或信息。
