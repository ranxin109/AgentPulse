# 批量操作与待确认状态

列表空白处、任务卡片以及最小化圆环的右键菜单均提供：

- **一键确认所有已完成任务**：所有未读的完成任务置灰、禁点，约 3 秒后播放退场，进入历史。进行中的任务不改变。查看详情或历史时会回到主列表展示退场。
- **一键清理故障任务**：默认范围为 Agent 明确报告 failed 的任务，以及 active/waiting 超时未更新的任务。清理前显示数量并确认，文件移到回收站，可以恢复。每项在锁内重新读取；若刚收到新进度就跳过。待确认、已完成、已阅任务不清理。正在写入或没有权限的文件保留，并提示部分失败。

“故障”清理范围包含超时提示，并不证明任务已失败。文件格式错误、无法解析的任务不在这个操作范围内，避免删除无法判断状态的数据。已有上报进程仍可能重新创建被清理的任务；清理不终止 Agent。

**待确认**的字段为 `awaiting_confirmation`，列表进度条、详情状态和圆环显示橙黄色。Agent 因等待用户确认、授权或必要信息而暂停时，先上报状态及所需决定，再提问；回复后切回 active/current。暂停状态不因长时间未更新变红。无需虚构进度或发送空心跳。

Agent 上报细节见 [AGENT_REPORTING.md](AGENT_REPORTING.md)。新增功能的构建和状态测试会记录在交付检查；桌面控制服务不可用时，不能把源码测试当作动画和菜单的实际验收。
