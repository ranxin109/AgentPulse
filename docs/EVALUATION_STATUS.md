# 评估建议落实情况

以下列出当前设计优化的实现情况与验证限制。

|评估项|当前处理|验证与限制|
|---|---|---|
|1. PowerShell 5.1 中文编码|三个脚本带 UTF-8 BOM；JSON 显式按 UTF-8 读|真正 5.1 与 7 中中文及无 BOM JSON 测试通过|
|2. 缩小任务触发范围|预计超过 2 分钟或至少 3 步才建任务|skill 规则已改；外部 AGENTS 若强制加载，仍有阅读成本，不承诺零 token|
|3. 文档瘦身、按需读协议|skill 入口自足，复杂协议按需，执行脚本不要求读源码|已结构校验；没有测量实际 token 节省|
|4. 增量 patch|顶层合并和按阶段 id 更新；稳定保留开始/已阅时间|发布测试覆盖合并、权重、时间和完成校验|
|5. new-task.ps1|自动生成 ID、阶段和初始时间|中文任务新建测试通过|
|6. 环境分支|有桌面工具时截图；无工具时一次备用启动并明确不可验证|环境分支已实现；降级 COM 启动仍可能受桌面环境影响、挂起，列入待改进|
|7. 状态目录可配置|TaskDirectory 参数、环境变量和组件首个参数；文档说明权限|隔离目录和环境变量测试通过；不会自动获得沙箱权限|
|可选预估与权重|预估可选，显式 weight 优先；旧预估中点兼容|等权与 1:3 权重测试通过|
|进度自报标识|skill、协议、详情均说明 Agent 自报性质|源码与桌面详情确认；没有独立模型工作校验接口|
|诚实条款|保留用户指定句子|入口、使用说明、上报和交接均保留|

**以下优化有对应实现，但组件尚未全部完成桌面验收。** 降级启动的可靠性、最终圆环重启复测、长详情滚动流畅度仍有具体待办。真实磨砂模糊也尚未实现，见开发交接。

本项目没有实际 token 成本测量，不将节省 token 的设计目标写成已验证收益。
