# 验证与验收边界

## 已通过的自动检查

- C# .NET Framework 编译与原生内置自检。
- PowerShell 5.1 和 7：中文、UTF-8 无 BOM 输入、新建、patch、权重、时间保留、阶段时间戳、完成校验及目录环境变量。
- skill 结构、示例 JSON、文档相对链接与发布包完整性。
- 隔离安装与重复安装：模拟任务及设置保持不变，不接触真实运行数据。
- 数据/几何自检：任务排序、待确认状态、故障清理资格、锁内重新检查、圆环透明边缘、工作区限制与自适应高度。

以上检查使用源码或虚构数据，不证明窗口在用户桌面可见，也不证明实际动画流畅。

## 尚待最终桌面验收

|项目|检查要求|
|---|---|
|圆环重启和首次进入位置|关闭后重启，进入圆环，核对保存位置；已使用 StartPosition.Manual 避免系统默认位置覆盖|
|长详情滚动与切换|连续快速滚动，检查重影、字体错位和切换流畅度；已加入合成绘制，但需要动态观察|
|多屏及不同 DPI|覆盖负坐标显示器、缩放变化、任务栏工作区和边缘缩放|
|大量任务性能|记录任务规模、硬件、测量方法和结果；尚无 FPS 测量|
|批量菜单与退场动画|实际点击清理/确认菜单，检查橙黄状态、灰色禁点及延迟退场|
|普通桌面启动与空状态|用户点击启动入口后观察可见窗口，检查无任务、已阅及读取失败提示|
